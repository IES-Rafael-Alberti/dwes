* Car Dealership CRUD in PHP
Creating a CRUD (Create, Read, Update, Delete) application for a car
dealership in PHP involves designing a suitable database schema. Below,
I'll outline a basic database structure with tables, attributes, types,
constraints, keys, and relationships. This schema is designed to manage
information about cars, brands, sellers, and clients.

** Database
*** Table: =CarBrand=
    :PROPERTIES:
    :CUSTOM_ID: table-carbrand
    :END:

- *Attributes:*

  - =id= (INT, primary key, auto-increment)
  - =name= (VARCHAR, unique, not null)

- *Primary Key:* =id=
- *Unique Key:* =name=
- *Purpose:* Stores different car brands.

*** Table: =Seller=
    :PROPERTIES:
    :CUSTOM_ID: table-seller
    :END:

- *Attributes:*

  - =id= (INT, primary key, auto-increment)
  - =name= (VARCHAR, not null)
  - =cars_selled= (INT, default 0)

- *Primary Key:* =id=
- *Purpose:* Stores information about car sellers.

*** Table: =Car=
    :PROPERTIES:
    :CUSTOM_ID: table-car
    :END:

- *Attributes:*

  - =id= (INT, primary key, auto-increment)
  - =model= (VARCHAR, not null)
  - =price= (DECIMAL(10,2), not null)
  - =condition= (VARCHAR, not null, values like 'new', 'refurbished')
  - =engine_features= (TEXT, nullable)
  - =gas_type= (VARCHAR, nullable)
  - =mileage= (INT, nullable)
  - =status= (VARCHAR, nullable)
  - =gears= (INT, nullable)
  - =license_plate= (VARCHAR, nullable)
  - =deposit_capacity= (DECIMAL(5,2), nullable)
  - =trunk_capacity= (DECIMAL(5,2), nullable)
  - =horse_power= (INT, nullable)
  - =brand_id= (INT, foreign key to CarBrand, not null)
  - =seller_id= (INT, foreign key to Seller, not null)

- *Primary Key:* =id=
- *Foreign Keys:*

  - =brand_id= references =CarBrand(id)=
  - =seller_id= references =Seller(id)=

- *Purpose:* Stores details about each car.

*** Table: =Client=
    :PROPERTIES:
    :CUSTOM_ID: table-client
    :END:

- *Attributes:*

  - =id= (INT, primary key, auto-increment)
  - =name= (VARCHAR, not null)

- *Primary Key:* =id=
- *Purpose:* Stores client information.

*** Table: =Purchase=
    :PROPERTIES:
    :CUSTOM_ID: table-purchase
    :END:

- *Attributes:*

  - =id= (INT, primary key, auto-increment)
  - =client_id= (INT, foreign key to Client, not null)
  - =car_id= (INT, foreign key to Car, not null)
  - =date= (DATE, not null)

- *Primary Key:* =id=
- *Foreign Keys:*

  - =client_id= references =Client(id)=
  - =car_id= references =Car(id)=

- *Purpose:* Records the purchases of cars by clients.

** Notes on the Database Design
    :PROPERTIES:
    :CUSTOM_ID: notes-on-the-database-design
    :END:

- *Normalization:* The database design should be normalized to at least
  the third normal form (3NF) to reduce redundancy and improve data
  integrity.
- *Data Types:* Choose appropriate data types for each field. For
  instance, =VARCHAR= for strings, =INT= for integers, =DECIMAL= for
  prices and capacities, and =DATE= for dates.
- *Constraints:*

  - =NOT NULL= constraints are used for mandatory fields.
  - =AUTO_INCREMENT= is used for primary keys to create unique
    identifiers for each row.
  - =UNIQUE= constraints ensure values like brand names are not
    duplicated.

- *Foreign Key Relationships:* These enforce referential integrity
  between tables. For example, each car is associated with a specific
  brand and seller.
- *Nullable Fields:* Fields like =engine_features=, =gas_type=,
  =mileage=, etc., are allowed to be =NULL= to accommodate varying
  levels of detail available for different cars.

This database structure provides a comprehensive foundation for a car
dealership system, enabling efficient data storage and retrieval for a
wide range of dealership operations.

* PHP and HTML Code
** List ALL Cars
   :PROPERTIES:
   :CUSTOM_ID: list-all-cars
   :END:

To create a simple HTML page and its corresponding PHP script for
listing all cars with their model, brand, and price in a car dealership
project, you'll need to follow these steps. This example assumes you
have a database with the necessary tables and data in place.

*** Step 1: Create the HTML Page
    :PROPERTIES:
    :CUSTOM_ID: step-1-create-the-html-page
    :END:

This page (=list_cars.html=) will be simple, primarily serving as a link

#+begin_src html
  <!DOCTYPE html>
  <html>
  <head>
      <title>Car Dealership - Car List</title>
  </head>
  <body>
      <h1>Car List</h1>
      <p>
          <a href="list_cars.php">View All Cars</a>
      </p>

  </html>
#+end_src

*** Step 2: Create the PHP Script
    :PROPERTIES:
    :CUSTOM_ID: step-2-create-the-php-script
    :END:

This PHP script (=list_cars.php=) will connect to the database, retrieve
the list of cars, and display the model, brand, and price. We'll use PDO
for database interaction with prepared statements.

#+begin_src php
  <?php
  $host = 'localhost';
  $db   = 'car_dealership';
  $user = 'root';      // Replace with your database username
  $pass = '';          // Replace with your database password
  $charset = 'utf8mb4';

  $dsn = "mysql:host=$host;dbname=$db;charset=$charset";
  $options = [
      PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
      PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
      PDO::ATTR_EMULATE_PREPARES   => false,
  ];

  try {
      $pdo = new PDO($dsn, $user, $pass, $options);
  } catch (\PDOException $e) {
      throw new \PDOException($e->getMessage(), (int)$e->getCode());
  }

  $stmt = $pdo->prepare("SELECT Car.model, Car.price, CarBrand.name AS brand FROM Car JOIN CarBrand ON Car.brand_id = CarBrand.id");
  $stmt->execute();

  echo "<h1>Car List</h1>";
  echo "<table border='1'><tr><th>Model</th><th>Brand</th><th>Price</th></tr>";
  while ($row = $stmt->fetch()) {
      echo "<tr><td>".$row["model"]."</td><td>".$row["brand"]."</td><td>".$row["price"]."</td></tr>";
  }
  echo "</table>";
  ?>
#+end_src

*** Explanation:
    :PROPERTIES:
    :CUSTOM_ID: explanation
    :END:

1. *Database Connection*: The script starts by setting up a PDO
   connection to the database.

2. *Prepared Statement*: A prepared statement is used to query the
   database. This query joins the =Car= and =CarBrand= tables to get the
   model, brand, and price of each car.

3. *Data Display*: The fetched data is displayed in an HTML table.

*** Note:
    :PROPERTIES:
    :CUSTOM_ID: note
    :END:

- Make sure to replace the =$host=, =$db=, =$user=, and =$pass=
  variables with your actual database host, database name, username, and
  password.
- The structure of the SQL query depends on your database schema. Adjust
  the field names and table names according to your actual database
  schema.
- Ensure that your PHP environment is correctly set up to connect to
  your MySQL database.

This setup provides a basic and secure way to list cars from your
database using PHP and PDO with prepared statements.

*** Step 2: Create the PHP Script for Displaying Car Details
    :PROPERTIES:
    :CUSTOM_ID: step-2-create-the-php-script-for-displaying-car-details
    :END:

This PHP script (=car_detail.php=) will connect to the database,
retrieve the details of the car with the given ID, and display them.
We'll continue using PDO for database interaction with prepared
statements.

#+begin_src php
  <?php
  $host = 'localhost';
  $db   = 'car_dealership';
  $user = 'root';      // Replace with your database username
  $pass = '';          // Replace with your database password
  $charset = 'utf8mb4';

  $dsn = "mysql:host=$host;dbname=$db;charset=$charset";
  $options = [
      PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
      PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
      PDO::ATTR_EMULATE_PREPARES   => false,
  ];

  try {
      $pdo = new PDO($dsn, $user, $pass, $options);
  } catch (\PDOException $e) {
      throw new \PDOException($e->getMessage(), (int)$e->getCode());
  }

  $carId = $_GET['car_id'] ?? ''; // Retrieve car ID from URL parameter

  if ($carId) {
      $stmt = $pdo->prepare("SELECT * FROM Car WHERE id = :carId");
      $stmt->bindParam(':carId', $carId, PDO::PARAM_INT);
      $stmt->execute();

      $car = $stmt->fetch();
      if ($car) {
          echo "<h1>Car Details</h1>";
          echo "<p>Model: " . htmlspecialchars($car["model"]) . "</p>";
          echo "<p>Brand: " . htmlspecialchars($car["brand"]) . "</p>";
          // Display other details like price, condition, engine features, etc.
      } else {
          echo "<p>Car not found.</p>";
      }
  } else {
      echo "<p>No car selected.</p>";
  }
  ?>
#+end_src

*** Explanation:
    :PROPERTIES:
    :CUSTOM_ID: explanation-1
    :END:

1. *Database Connection*: The script sets up a PDO connection to the
   database.

2. *Retrieving Car ID*: The car ID is obtained from the URL parameter
   (=$_GET['car_id']=).

3. *Query and Display Car Details*: A prepared statement is used to
   retrieve and display the details of the car with the provided ID. The
   data is sanitized using =htmlspecialchars= to prevent XSS attacks.

*** Note:
    :PROPERTIES:
    :CUSTOM_ID: note-1
    :END:

- Replace the database connection details (=$host=, =$db=, =$user=,
  =$pass=) with your actual database information.
- Ensure your table and column names in the SQL query match those in
  your database schema.
- The script assumes that the =Car= table contains all necessary columns
  like =model=, =brand=, =price=, =condition=, etc. Modify the script to
  include all relevant details as per your database schema.
- This setup provides a basic and secure way to display detailed
  information about a car from your database using PHP and PDO. For a
  more user-friendly interface, you might consider adding error handling
  for invalid IDs and styling the output with CSS.

*** Step 2: Create the PHP Script for Form Handling
    :PROPERTIES:
    :CUSTOM_ID: step-2-create-the-php-script-for-form-handling
    :END:

Create a PHP script (=insert_car.php=) to handle the form submission.
This script will insert the new car details into your database.

#+begin_src php
  <?php
  $host = 'localhost';
  $db   = 'car_dealership';
  $user = 'root';      // Replace with your database username
  $pass = '';          // Replace with your database password
  $charset = 'utf8mb4';

  $dsn = "mysql:host=$host;dbname=$db;charset=$charset";
  $options = [
      PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
      PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
      PDO::ATTR_EMULATE_PREPARES   => false,
  ];

  try {
      $pdo = new PDO($dsn, $user, $pass, $options);
  } catch (\PDOException $e) {
      throw new \PDOException($e->getMessage(), (int)$e->getCode());
  }

  if ($_SERVER["REQUEST_METHOD"] == "POST") {
      $stmt = $pdo->prepare("INSERT INTO Car (model, brand, price, condition, engine_features, gas_type, mileage, status, gears, license_plate, deposit_capacity, trunk_capacity, horse_power) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)");

      $stmt->execute([
          $_POST['model'],
          $_POST['brand'],
          $_POST['price'],
          $_POST['condition'] ?? null,
          $_POST['engine_features'] ?? null,
          $_POST['gas_type'] ?? null,
          $_POST['mileage'] ?? null,
          $_POST['status'] ?? null,
          $_POST['gears'] ?? null,
          $_POST['license_plate'] ?? null,
          $_POST['deposit_capacity'] ?? null,
          $_POST['trunk_capacity'] ?? null,
          $_POST['horse_power'] ?? null
      ]);

      echo "New car added successfully.";
  }
  ?>
#+end_src

*** Explanation
    :PROPERTIES:
    :CUSTOM_ID: explanation-2

- The PHP script connects to the database and uses a prepared statement
  to insert the car data. It uses the POST method to retrieve data from
  the form.
- Null coalescing operators (=??=) are used for optional fields to
  handle cases where no data is entered.
- Proper error handling should be implemented for a production
  environment (e.g., try-catch blocks, validation of input data).

- This example does not include client-side or server-side validation
