Creating functions is a fundamental aspect of PHP programming. Here are
several exercises that focus on writing and utilizing functions in PHP.
These exercises are designed to help reinforce your understanding of how
to define, call, and work with functions, as well as to practice passing
parameters and returning values.

*** Exercise 1: Greeting Function
    :PROPERTIES:
    :CUSTOM_ID: exercise-1-greeting-function
    :END:

*Objective*: Write a function named =greet= that takes a name as a
parameter and prints "Hello, [name]!". Call this function with different
names.

*** Exercise 2: Sum Function
    :PROPERTIES:
    :CUSTOM_ID: exercise-2-sum-function
    :END:

*Objective*: Create a function called =sum= that takes two numbers as
parameters and returns their sum. Test this function with different
pairs of numbers.

*** Exercise 3: Temperature Conversion
    :PROPERTIES:
    :CUSTOM_ID: exercise-3-temperature-conversion
    :END:

*Objective*: Write a function named =convertToFahrenheit= that converts
Celsius to Fahrenheit. The formula is =(celsius * 9/5) + 32=. Test your
function with different Celsius values.

*** Exercise 4: String Reversal
    :PROPERTIES:
    :CUSTOM_ID: exercise-4-string-reversal
    :END:

*Objective*: Develop a function called =reverseString= that takes a
string and returns it reversed. Test this function with various strings.

*** Exercise 5: Area Calculator
    :PROPERTIES:
    :CUSTOM_ID: exercise-5-area-calculator
    :END:

*Objective*: Create a function named =calculateArea= that takes the
radius of a circle as a parameter and returns its area (use =πr²= for
area calculation). Test the function with different radii.

*** Exercise 6: Factorial Function
    :PROPERTIES:
    :CUSTOM_ID: exercise-6-factorial-function
    :END:

*Objective*: Write a recursive function named =factorial= that
calculates and returns the factorial of a number. Recall that the
factorial of a number is the product of all positive integers less than
or equal to the number.

*** Exercise 7: Prime Number Checker
    :PROPERTIES:
    :CUSTOM_ID: exercise-7-prime-number-checker
    :END:

*Objective*: Develop a function named =isPrime= that determines if a
number is prime or not. The function should return a boolean value. Test
the function with various numbers.

*** Exercise 8: HTML Tag Wrapper
    :PROPERTIES:
    :CUSTOM_ID: exercise-8-html-tag-wrapper
    :END:

*Objective*: Create a function named =wrapInTag= that takes two
parameters: a string and an HTML tag name. The function should return
the string wrapped inside the specified HTML tag. For example,
=wrapInTag("Hello, world!", "h1")= should return
=<h1>Hello, world!</h1>=.

*** Exercise 9: Array Filter
    :PROPERTIES:
    :CUSTOM_ID: exercise-9-array-filter
    :END:

*Objective*: Write a function named =filterArray= that takes an array of
numbers and a threshold number as parameters. The function should return
a new array consisting of numbers from the original array that are
greater than the threshold.

*** Exercise 10: Multiplication Table Generator
    :PROPERTIES:
    :CUSTOM_ID: exercise-10-multiplication-table-generator
    :END:

*Objective*: Develop a function called =generateMultiplicationTable=
that takes a number and generates its multiplication table up to 10. The
function should return a two-dimensional array representing the table.

--------------

These exercises are designed to offer a range of challenges, from basic
function creation and usage to more complex operations involving arrays,
recursion, and string manipulation. Remember, the key to mastering
functions in PHP is practice and experimentation.
