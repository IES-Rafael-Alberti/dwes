Here's a list of functions for working with arrays in PHP grouped by
functionality:

*Array creation and initialization:* * =array()=: Creates an empty array
or initializes an array with a set of values. * =count()=: Returns the
number of elements in an array. * =in_array()=: Checks whether a
specific value exists in an array.

*Array manipulation and modification:* * =array_push()=: Adds one or
more elements to the end of an array. * =array_pop()=: Removes and
returns the last element of an array. * =array_shift()=: Removes and
returns the first element of an array. * =array_unshift()=: Adds one or
more elements to the beginning of an array. * =array_splice()=: Removes
and replaces elements from an array. * =isset()=: Checks whether a
specific key exists in an array. * =empty()=: Checks whether an array is
empty. * =unset()=: Removes one or more elements from an array.

*Array iteration and searching:* * =foreach()=: Iterates over the
elements of an array. * =array_keys()=: Returns an array of all the keys
in an array. * =array_values()=: Returns an array of all the values in
an array. * =array_search()=: Finds the first occurrence of a specific
value in an array.

*Array sorting and filtering:* * =sort()=: Sorts an array in ascending
order. * =rsort()=: Sorts an array in descending order. * =asort()=:
Sorts an associative array by value. * =arsort()=: Sorts an associative
array by value in descending order. * =ksort()=: Sorts an associative
array by key. * =krsort()=: Sorts an associative array by key in
descending order. * =array_filter()=: Filters an array based on a
callback function.

*Array merging and combining:* * =array_merge()=: Merges two or more
arrays into one. * =array_slice()=: Extracts a portion of an array to
create a new array. * =array_unique()=: Removes duplicate values from an
array. * =array_fill()=: Creates a new array with a specified value and
a range of keys.

*Array accessing and manipulating elements:* * =array_keys()=: Returns
an array of all the keys in an array. * =array_values()=: Returns an
array of all the values in an array. * =array_chunk()=: Divides an array
into smaller subarrays. * =array_combine()=: Creates an associative
array from two arrays of keys and values. * =array_map()=: Applies a
callback function to each element in an array. * =array_reduce()=:
Reduces an array to a single value using a callback function.

These functions provide a comprehensive set of tools for working with
arrays in PHP, covering a wide range of tasks from creating and
manipulating arrays to searching, sorting, and filtering them.
