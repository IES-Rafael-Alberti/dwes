# Modalidad de prácticas y evaluación — UD4 (2026/2027)

## Práctica evaluable

GTask PHP 8.4 será la práctica cooperativa principal del bloque OOP y capas.
Notes procedural se usará como práctica formativa o como incremento acotado,
pero no como una segunda corrección completa para cada alumno.

Cada integrante debe implementar un caso de uso completo con entrada HTTP,
validación, dominio/aplicación, PDO o repositorio, respuesta/error y tests.
Las consultas preparadas, escape de salida, sesiones, contraseñas,
autorización y transacciones deben aparecer en los slices que correspondan.

## Entrega y defensa

El grupo entrega repositorio basado en template, README, issue de entrega,
pruebas y colección REST o guion de llamadas. Todos entregan el enlace en
Moodle. La defensa pregunta individualmente por el slice y por una medida de
seguridad.

Los ejercicios de fundamentos se mantienen para práctica formativa y como
fuente de preguntas Moodle. El concesionario histórico no vuelve al recorrido
evaluable.
