# UD3 — Spring Boot MVC

Construiremos aplicaciones web renderizadas en el servidor con **Spring Boot 4, Java 25 y Thymeleaf**. La unidad termina con un Gestor de tareas que protege sesión, CSRF y propiedad de los recursos.

## Ruta de aprendizaje

1. [Fundamentos de MVC](../ud03-mvc-spring-boot/01-documentacion/01-fundamentos-mvc.md): responsabilidades y ciclo petición-respuesta.
2. [Controladores y vistas](../ud03-mvc-spring-boot/01-documentacion/02-controladores-y-vistas.md): rutas, modelo y respuestas.
3. [Thymeleaf](../ud03-mvc-spring-boot/01-documentacion/03-thymeleaf.md): salida, colecciones, enlaces y formularios.
4. [Formularios, validación y PRG](../ud03-mvc-spring-boot/01-documentacion/04-formularios-validacion-prg.md): entrada segura y redirecciones.
5. [Productos incremental](../ud03-mvc-spring-boot/03-ejercicios/TareaSpringMVC-Productos/TareaSpringMVC-Productos.md): práctica TDD por checkpoints.
6. [Persistencia](../ud03-mvc-spring-boot/01-documentacion/05-persistencia.md): form object, servicio, repositorio y entidad.
7. [Gestor de tareas seguro](../ud03-mvc-spring-boot/01-documentacion/06-gestor-tareas-seguro.md): integración con sesión y autorización por propietario.

## Objetivos y evaluación

La [guía completa de UD3](../ud03-mvc-spring-boot/README.md) recoge objetivos, prerrequisitos, RA/CE, evidencias y alcance. Productos es la práctica incremental; el Gestor es el ejemplo integrador guiado.

## Seguridad

La [guía de seguridad MVC](../ud03-mvc-spring-boot/06-seguridad/README.md) reúne el modelo de amenazas y la lista de comprobación: CSRF, XSS, validación servidor, sesión y autorización por propietario.

Mustache se conserva únicamente como comparación sintáctica opcional. Las soluciones, cuestionarios y guías docentes quedan fuera de GitHub Pages.
