# UD3 — Spring Boot MVC

En esta unidad construiremos aplicaciones web renderizadas en el servidor con Spring MVC. Empezaremos por el flujo controlador-vista y terminaremos con formularios validados y autenticación basada en sesión.

## Ruta de aprendizaje

1. Repasa el patrón MVC y el ciclo petición-respuesta.
2. Implementa controladores y vistas con Thymeleaf.
3. Compara Thymeleaf con Mustache en el ejemplo guiado.
4. Añade formularios, validación y mensajes de error.
5. Protege operaciones con CSRF y autenticación por sesión.

## Propósito

Desarrollar aplicaciones web con Spring Boot MVC usando Thymeleaf y Mustache.

## Contenidos

- Spring MVC: controladores, vistas, formularios
- Thymeleaf y Mustache
- Validación de formularios
- Seguridad CSRF y autenticación basada en sesión

## Evaluación

- Tarea Spring MVC (individual)
- Cuestionarios semanales

## Requisitos

- Java 17 o superior
- Maven o Gradle Wrapper, según el proyecto
- Conocimientos de Spring Boot, HTTP y persistencia JPA
