# UD4 — PHP

## Propósito

Aprender PHP desde cero hasta desarrollo OOP con CRUD, como base para Laravel.

## Contenidos

- PHP básico: sintaxis, condicionales, bucles, arrays, funciones
- PHP avanzado: formularios, sesiones, cookies, BBDD
- CRUD con PHP
- PHP orientado a objetos
- PHP OOP CRUD
- phpDocumentor
- PHP necesario para Laravel 12

## Evaluación

- Ejercicios progresivos (individuales)
- Tarea rápida PHP
- Cuestionarios semanales (Moodle GIFT)
