# UD0 — Previos

## Propósito

Nivelar conocimientos previos necesarios para el módulo: Java moderno (17-21) para estudiantes con base en Kotlin, modelado de datos NoSQL (MongoDB) y JSON en PostgreSQL.

## Contenidos

- **Java 17-21**: records, pattern matching, switch expressions, sealed types, virtual threads
- **MongoDB**: modelado de documentos frente a SQL
- **PostgreSQL JSON**: operaciones con JSON/JSONB
- **GeoNotes**: proyecto guiado de Java con Gradle

## Evaluación

- Tarea GeoNotes (individual)
- Ejercicios de MongoDB y PostgreSQL JSON
