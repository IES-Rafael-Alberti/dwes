# UD0 — Previos

## Propósito

Nivelar conocimientos previos necesarios para el módulo: Java moderno para estudiantes con base en Kotlin, modelado de datos NoSQL (MongoDB) y JSON en PostgreSQL. El entorno oficial del curso es **Java 25 LTS**.

## Contenidos

- **Java 17 y 21 como hitos**: records, sealed types, pattern matching, switch expressions, sequenced collections y virtual threads
- **Java 22-25**: variables sin nombre, comentarios Markdown, gatherers, scoped values, constructores flexibles, archivos fuente compactos e importación de módulos
- **MongoDB básico**: documentos, colecciones, CRUD y consultas
- **MongoDB**: modelado de documentos frente a SQL
- **PostgreSQL JSON**: operaciones con JSON/JSONB
- **GeoNotes**: proyecto guiado de Java con Gradle

## Evaluación

- Tarea GeoNotes (por parejas)
- Ejercicios de MongoDB y PostgreSQL JSON

## Política de versiones

- Los proyectos, ejercicios y pruebas evaluables usan **JDK 25 LTS** sin características preview.
- Java 17 y Java 21 se explican para comprender código existente y el origen de las características modernas.
- Java 26 y Java 27 son versiones no LTS; solo se mencionan como evolución posterior y no forman parte de la evaluación.
