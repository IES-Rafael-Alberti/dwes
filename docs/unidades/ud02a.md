# UD2a — API REST con Spring Boot

## Propósito

Aprender a diseñar e implementar APIs REST con Spring Boot 4, aplicando TDD desde el primer endpoint.

## Contenidos

- Controladores REST, DTOs, validación
- Capa de servicios y repositorios
- JPA / Hibernate
- Seguridad con JWT y roles
- Testing de APIs
- Documentación con OpenAPI

## Evaluación

- Ejercicios de API REST (individuales)
- Proyecto de API con TDD
- Cuestionarios semanales
