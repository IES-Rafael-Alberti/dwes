# UD5 — Laravel 12 API-first

## Propósito

Construir APIs REST seguras con Laravel 12. La unidad continúa el trabajo explícito de PHP 8.4: Sail aísla el entorno, Eloquent sustituye PDO manual, Form Requests centraliza la validación y Policies protegen recursos por propietario.

- Incrementos RED -> GREEN -> REFACTOR sobre la API de recetas.
