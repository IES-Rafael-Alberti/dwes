# UD1 — Introducción al entorno servidor

## Propósito

Comprender la ejecución web en cliente y servidor, seleccionar tecnologías de backend con criterio y preparar un entorno reproducible con Java 25 y Spring Boot 4.

## Contenidos

- Cliente, servidor y contenido dinámico
- Mecanismos de ejecución y arquitecturas de servidor
- Lenguajes, runtimes, herramientas y frameworks
- Integración de HTML y código servidor
- HTTP/1.1, HTTP/2, HTTP/3 y método QUERY
- HTTPS/TLS, cookies y cabeceras de seguridad
- Entorno Java 25 y primer servidor Spring Boot 4 probado

## Evaluación

- Laboratorio HTTP con trazas sanitizadas
- Comparación razonada de tecnologías
- Servidor mínimo reproducible
- Cuestionario alineado con RA1.a-g
