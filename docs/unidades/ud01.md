# UD1 — Introducción al entorno servidor

## Propósito

Introducir los conceptos fundamentales del desarrollo web en entorno servidor: protocolo HTTP, instalación de herramientas y primer contacto con el backend.

## Contenidos

- Conceptos de servidor web
- Protocolo HTTP: métodos, cabeceras, códigos de estado
- Instalación y configuración del entorno de desarrollo
- Primer contacto con Spring Boot

## Evaluación

- Cuestionarios semanales (Moodle GIFT)
- Ejercicios de HTTP y configuración
