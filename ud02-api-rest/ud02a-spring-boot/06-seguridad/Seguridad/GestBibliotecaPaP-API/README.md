# Biblioteca — archivo de consulta organizado por temas

Este ejemplo histórico complementa la ruta canónica de UD2a. La reorganización
conserva sus fuentes y PDF; no certifica la actualización técnica de cada guía.

- `01-recorrido/`: las seis etapas paso a paso, con sus fuentes Org cuando existen.
- `02-persistencia/`: unicidad y referencias circulares, fuentes y PDF existentes.
- `03-validacion/`: validación de entradas.
- `04-enunciados/`: planteamiento de Biblioteca y Gestión de Préstamos.
- `Documentos/01-modelo-y-dtos/`: DTOs y refactorización del usuario.
- `Documentos/02-pruebas/`: pruebas de controladores.
- `Documentos/03-autenticacion-y-roles/`: JWT, roles y tokens.
- `Documentos/04-http-y-transporte/`: recorrido HTTP, cookies y HTTPS.
- `GestionBiblioteca/`: código del ejemplo; conserva su estructura de aplicación.

El diagrama entidad-relación permanece en esta carpeta como recurso compartido.
