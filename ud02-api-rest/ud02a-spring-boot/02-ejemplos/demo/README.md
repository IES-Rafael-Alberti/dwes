# Demo mínima de Tasks

Este proyecto es una API pequeña de tareas para explorar un esqueleto Spring
Boot. No sustituye Battleship ni se evalúa de forma independiente.

## Cuándo usarlo

- Para comprobar rápidamente Maven, H2 y un controlador REST básico.
- Como sandbox antes de seguir la ruta de [Battleship](../battleship/docs/README.md).

La ruta canónica de UD2a está en la [teoría](../../01-documentacion/README.md)
y en Battleship. No añadas funcionalidades nuevas aquí si pertenecen al
recorrido docente principal.
