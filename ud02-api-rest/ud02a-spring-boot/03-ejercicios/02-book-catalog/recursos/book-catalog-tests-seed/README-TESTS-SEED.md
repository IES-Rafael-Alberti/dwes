# Tests semilla — ubicación vigente

Los tests corregidos de las seis entregas se han integrado en el starter:
`../book-catalog-template/classroom/tests-seed/`.

Se distribuyen dentro del mismo repositorio plantilla. Desde su raíz se activa
solo un checkpoint con `java classroom/ActivarEntrega.java N` (N entre 1 y 6).
No copies todas las entregas a `src/test` a la vez. Las plantillas de issue
antiguas de esta carpeta no sustituyen las instrucciones del repositorio actual.
