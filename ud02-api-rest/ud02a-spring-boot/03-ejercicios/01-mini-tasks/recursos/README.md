# Recursos de Mini Spring Boot Tasks

Este directorio contiene dos recursos con funciones distintas:

| Recurso | Clasificación | Uso |
| --- | --- | --- |
| `mini-spring-boot-tasks-git-lesson/` | Kit requerido | El script usa los snapshots para reconstruir commits y tags pedagógicos. No edites los snapshots. |
| `mini-spring-boot-tasks-completo/` | Referencia completa | Sirve para verificación docente o revisión posterior a la entrega; no es el punto de partida. |

Sigue siempre el [enunciado del ejercicio](../README.md). La actividad evalúa
la interpretación de la evolución arquitectónica y la capacidad de explicar
las pruebas, no la copia de una versión final.
