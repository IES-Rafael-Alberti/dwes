# Ejercicios evaluables de UD2a

Estos tres ejercicios aplican de forma individual los conceptos presentados en
Battleship. No son rutas alternativas: Battleship es el proyecto conductor y
cada ejercicio aporta una evidencia evaluable concreta.

| Ejercicio | Peso publicado | Aplicación principal |
| --- | ---: | --- |
| [Mini Spring Boot Tasks](01-mini-tasks/README.md) | 20 % | Evolución por capas, Git y pruebas |
| [Book Catalog API](02-book-catalog/README.md) | 25 % | TDD, DTOs, servicios y errores |
| [Gestión de eventos](03-gestion-eventos/README.md) | 25 % | JWT, roles, CORS y pruebas de seguridad |

## Ruta de trabajo

1. Estudia la [sesión correspondiente de Battleship](../02-ejemplos/battleship/docs/README.md).
2. Lee el enunciado, `ra-ce.md` y `rubrica.md` del ejercicio.
3. Usa únicamente el starter o kit indicado en su README.
4. Ejecuta las pruebas y explica la evidencia entregada.

La [guía de evaluación](../EVALUACION.md) reúne las ponderaciones publicadas y
la cobertura de criterios.
