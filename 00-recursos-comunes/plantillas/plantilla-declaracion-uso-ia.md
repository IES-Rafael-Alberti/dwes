# Declaración de uso de IA

> Cada ejercicio o proyecto que permita o exija IA debe incluir esta declaración cumplimentada. La IA puede ayudar, pero la autoría exige verificar, comprender y defender el resultado.

## 1. Resumen

| Campo | Respuesta |
|---|---|
| Ejercicio/Proyecto | |
| Alumno/a o grupo | |
| Fecha | |
| ¿Se ha usado IA? | Sí / No |
| Herramientas | Ej.: ChatGPT, Claude, Copilot, Gemini, GitHub Copilot... |
| Ámbitos de uso | Código / pruebas / documentación / depuración / diseño |

Si no se ha usado IA, indica **No**, completa la identificación y firma.

## 2. Registro de usos materiales

Registra cada resultado de IA que hayas incorporado, adaptado o descartado tras una decisión técnica. No incluyas secretos, datos personales ni datos privados en prompts o capturas.

|---|---|---|---|---|---|
| 1 | | | `<tests, documentación oficial, comprobación manual, revisión…>` | | |
| 2 | | | | | |

## 3. Explicación y defensa

Para cada uso relevante, prepara una explicación breve de:

- qué problema intentabas resolver y por qué recurriste a IA;
- qué parte aceptaste, cambiaste o rechazaste y por qué;
- cómo comprobaste que era correcta, segura y adecuada al proyecto;
- qué pruebas, documentación oficial, fuentes o comprobaciones manuales respaldan esa decisión.

## 4. Declaración

Declaro que:

- he registrado el uso material de IA o he indicado expresamente que no la usé;
- he verificado y comprendo cualquier resultado incorporado;
- puedo localizar, explicar y defender las decisiones, código y pruebas afectados;
- no he introducido secretos, datos personales ni datos privados del proyecto en las consultas a IA.
