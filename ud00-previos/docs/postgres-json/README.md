# PostgreSQL JSON y JSONB — Curso exprés

## Objetivo
Aprender cuándo y cómo usar tipos JSON/JSONB en PostgreSQL como alternativa a MongoDB para datos semiestructurados, sin perder las ventajas de una BD relacional (integridad referencial, joins, transacciones ACID).

## Estructura (3 sesiones)
| Sesión | Tema | Duración estimada |
|--------|------|-------------------|
| 1 | JSONB vs relacional: GIN indexes, contención, cuándo cada uno | 90-120 min |
| 2 | Operaciones avanzadas: jsonb_set, triggers, vistas materializadas | 90-120 min |
| 3 | Comparativa real: Mongo vs Postgres JSONB — benchmark y conclusiones | 90-120 min |

## Metodología
Teoría → demo guiada → ejercicio autónomo → día de dudas.

## Prerrequisitos
- PostgreSQL 15+ instalado
- Conocimientos básicos de SQL (SELECT, INSERT, índices)
- Nociones de MongoDB (estructura de documentos)

## Evaluación
- Ejercicios autónomos (60%)
- Mini-benchmark comparativo (40%)
