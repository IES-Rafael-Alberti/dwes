# J25-07 - Historial de Calc25

Amplia `ud00-previos/03-ejercicios/02-calculadora/recursos/calc25/` sin tocar
el lexer ni el parser.

- Crea un `History` que conserve las ultimas operaciones y resultados.
- Usa un `record` para cada entrada.
- Anade el comando `history` al REPL.
- Anade tests para el limite del historial y para el orden mas reciente.
- No guardes datos en un fichero todavia; esa sera una ampliacion posterior.

La solucion docente contiene una implementacion minima y un parche orientativo
para `Main`. El alumnado debe integrar el cambio y mantener los tests previos.
