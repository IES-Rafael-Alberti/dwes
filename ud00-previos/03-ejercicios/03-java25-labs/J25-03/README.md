# J25-03 - Record de temperatura

Modela una temperatura con un `record` llamado `Temperature`.

- Guarda grados Celsius.
- Rechaza valores inferiores al cero absoluto.
- Expone `fahrenheit()` como metodo derivado.
- Mantiene la igualdad y el `toString()` generados por el `record`.

Compara esta solucion con una clase Java clasica con campo privado, constructor,
getter, `equals`, `hashCode` y `toString`.
