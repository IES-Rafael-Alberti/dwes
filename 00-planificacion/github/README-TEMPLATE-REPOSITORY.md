# Especificación de repositorio plantilla DWES

Crear en GitHub un template por stack o práctica, nunca uno por grupo. El
template debe incluir únicamente material inicial:

- README de arranque y entrega.
- Código inicial y tests iniciales, si proceden.
- `.gitignore` sin secretos.
- Configuración de ejemplo (`.env.example`, nunca valores reales).
- Licencia o aviso de uso del material.
- Issue templates para hito y entrega.
- Etiquetas `hito`, `pruebas`, `seguridad`, `documentacion`.

No debe incluir solución final, respuestas GIFT, rúbricas privadas ni datos de
alumnos. El nombre de la organización y los repositorios remotos quedan como
decisión docente pendiente; `gh_entregas.py` no los presupone.
