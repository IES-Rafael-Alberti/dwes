# Protocolo de accesibilidad y evaluación — DWES 2026/2027

Este protocolo prepara una respuesta común para cualquier alumno que necesite
adaptaciones de acceso, ritmo, comunicación o forma de respuesta. Describe
necesidades funcionales, no diagnósticos, y no sustituye el informe ni las
orientaciones del departamento de orientación.

## Principio de actuación

- Mantener los mismos resultados de aprendizaje, criterios de evaluación,
  contenidos esenciales y ponderaciones.
- Adaptar el medio, el ritmo, el puesto, la herramienta y la forma de demostrar
  el aprendizaje cuando la velocidad motora no sea el objeto evaluado.
- No penalizar el tiempo de tecleo, la caligrafía, el uso de ratón o la postura
  cuando no formen parte del criterio técnico.
- Acordar las medidas con el alumno, orientación y, cuando proceda, la familia;
  revisarlas después de las primeras actividades reales.
- Registrar las medidas en el seguimiento docente individual, sin incluir la
  condición personal en repositorios, rúbricas públicas o entregas.

## Medidas de acceso

Antes de la primera tarea práctica se comprobará, con el alumno, qué opción le
resulta funcional:

- puesto accesible, espacio de maniobra y periféricos que pueda utilizar;
- teclado, ratón, trackball, joystick, pulsadores, dictado o software de apoyo
  autorizado por el centro;
- atajos, autocompletado, plantillas y repositorios iniciales para reducir
  tecleo mecánico, sin proporcionar la solución evaluada;
- posibilidad de programar una pausa breve y cambiar de postura sin perder el
  trabajo;
- asiento y ubicación que no obliguen a mantener una postura dolorosa o a
  desplazarse innecesariamente;
- instrucciones fragmentadas, por escrito y con los pasos esenciales visibles.

El centro debe confirmar qué dispositivos y software están disponibles y quién
presta apoyo técnico. No se presupone que un compañero escriba o programe la
parte que se está acreditando individualmente.

## Tiempos y entregas

Como referencia inicial a validar, puede proponerse un **50 % adicional** en
cuestionarios, pruebas o tareas con límite temporal. No se aplicará
automáticamente: se concretará para cada alumno y cada instrumento. Si el
problema principal es la fatiga, se priorizarán además sesiones divididas y pausas
breves sobre una única sesión muy larga.

- Prácticas de varias sesiones: entregar por cortes funcionales, con una sesión
  adicional o una ampliación equivalente cuando el tiempo de tecleo sea el
  factor limitante.
- Entregas Moodle y repositorios: no cerrar el plazo en mitad de una sesión de
  aula si la evidencia ya está terminada; permitir la entrega hasta el plazo
  adaptado acordado.
- Cuestionarios: preferir intentos sin presión de velocidad, tiempo ampliado y
  pausas si la configuración de Moodle lo permite.
- Exámenes prácticos: dividir en bloques, guardar tras cada bloque y permitir
  reanudar después de una pausa. El tiempo se medirá desde la disponibilidad real
  para trabajar, no desde una explicación o incidencia técnica.

La cifra del 50 % es una propuesta de partida, no una regla automática. Se
ajustará con orientación y con evidencias de fatiga, velocidad y autonomía.

## Instrumentos de DWES

| Instrumento | Adaptación prevista |
|---|---|
| Práctica cooperativa | Mantener el slice y sus criterios; permitir cortes intermedios, herramientas de acceso y una ampliación de tiempo. La defensa puede hacerse sentado, con repositorio y preguntas anticipadas por escrito. |
| Defensa individual | Preguntas breves, una cada vez, tiempo de procesamiento y respuesta oral, señalando código o usando una demostración preparada. No exigir localizar rápidamente archivos o teclear un cambio si esa rapidez no se evalúa. |
| Hito individual | Mantener el flujo técnico mínimo; facilitar plantilla, pausas y entrega por incrementos. Aceptar explicación oral o dictada para README cuando la escritura no sea el criterio. |
| Cuestionario Moodle | Tiempo adaptado, interfaz accesible, bloques razonables y pausas. Evitar que la rapidez de lectura o interacción sea el criterio salvo que esté justificado. |
| Examen práctico, si se incorpora | Anunciarlo con antelación, probar el puesto y la herramienta, conceder tiempo adaptado, permitir pausas y guardar por bloques. No usar un examen sorpresa como primera comprobación. |

## Exámenes no publicados actualmente

El módulo no tiene ahora un examen global programado. Si se incorpora, antes de
publicarlo se revisará su duración, formato y necesidad. La adaptación no debe
consistir solo en añadir minutos: también debe contemplar acceso al puesto,
fatiga, pausas, forma de respuesta y posibilidad de demostrar el mismo criterio
mediante código preparado, explicación oral o dictado cuando proceda.

## Seguimiento

Después de UD1 y del primer cuestionario se registrará únicamente:

- medida aplicada;
- tiempo real necesario y pausas;
- barrera observada;
- evidencia conseguida;
- ajuste para la siguiente actividad.

La primera revisión decidirá si el tiempo adicional acordado es suficiente,
excesivo o debe sustituirse por más sesiones y entregas fraccionadas.

## Ficha interna de concreción

Para cada alumno se conservará una ficha no publicada con esta información:

- barrera funcional observada o comunicada;
- medida de acceso y herramienta autorizada;
- tiempo adicional, pausas o división de sesiones;
- forma alternativa de respuesta, si procede;
- instrumento en el que se aplica;
- fecha de revisión y resultado observable.

La ficha no debe incluir más información personal de la necesaria para aplicar la
medida. Si no existe información formal suficiente, se empezará por preguntar al
alumno qué le permite trabajar con autonomía y se dejará constancia de la
consulta al equipo correspondiente.
