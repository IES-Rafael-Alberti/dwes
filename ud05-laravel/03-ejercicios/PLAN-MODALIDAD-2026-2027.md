# Modalidad de prácticas y evaluación — UD5 (2026/2027)

## Práctica evaluable

La API Laravel 12 de recetas será la única ruta práctica principal. El proyecto
cooperativo se construirá por incrementos sobre el stack canónico, sin duplicar
las variantes Laravel 10/11, Blade o Vue.

Cada integrante tendrá un endpoint o caso de uso vertical: ruta y request,
servicio/controlador, modelo y migración, policy/autorización, resource,
validación y tests. Las responsabilidades compartidas deberán estar anotadas en
el README y revisadas por otro integrante.

## Entrega y defensa

Se exige repositorio, README, issue, migraciones reproducibles, tests y
demostración REST. Todos los integrantes entregan el enlace en Moodle. La
defensa de 5-10 minutos pregunta por una decisión de Eloquent/migración y por un
caso de autorización o error.

Los proyectos históricos se conservan como referencia, no como entregas
adicionales.
