# Hito individual 1 — servidor mínimo verificable

## Finalidad

Este hito individual se realizará aproximadamente al final del primer
trimestre, antes de la incorporación a las prácticas en empresa. Verifica que
cada alumno puede construir y explicar un flujo de servidor sin depender de un
grupo.

## Alcance mínimo

Partiendo del repositorio plantilla indicado por el docente, implementa un
servidor pequeño con:

- un recurso o caso de uso delimitado;
- un endpoint o flujo HTTP completo;
- una regla de validación o negocio;
- persistencia mediante la tecnología indicada;
- una respuesta correcta y un error controlado;
- tests escritos antes de la implementación de la regla principal;
- README con arranque, pruebas y decisiones.

No se exige cliente gráfico. El flujo puede demostrarse con Insomnia, Postman u
otro cliente REST.

## Entrega

- Enlace al repositorio individual.
- README y migraciones/configuración segura.
- Tests y resultado de ejecución.
- Colección REST o guion de llamadas.
- Declaración de uso de IA.

## Defensa

La defensa será individual y breve. Se podrá pedir localizar el endpoint, la
regla, la persistencia, el test y el tratamiento del error, o realizar un cambio
pequeño dirigido.

## Estado de evaluación

El hito acredita individualmente RA1, RA5 y RA7 mediante los criterios comunes
de arquitectura, modificación funcional, validación y pruebas. Se registra en
Moodle como evidencia individual, excluida del cálculo de categorías y del total
del curso: concreta la valoración por RA/CE y no añade una ponderación
independiente a UD2a.
